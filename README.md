# Штамп для дайсов

Статическая страница: открываете STL или собираете куб в генераторе, кликаете по грани и ставите текст, эмодзи, значок из библиотеки или SVG. Знак можно вдавить в тело или поднять рельефом, затем сохранить новый STL и проверить кубик броском в лотке.

[![Демо](https://img.shields.io/badge/🌐-Демо-success?style=for-the-badge)](https://volkula.github.io/dnd-dice-stamp/)
[![GitHub](https://img.shields.io/badge/GitHub-Репозиторий-blue?style=for-the-badge&logo=github)](https://github.com/Volkula/dnd-dice-stamp)

Модель должна быть цельным телом без дыр. Единицы знака совпадают с единицами STL, обычно это миллиметры.

## Что умеет

- **Генератор кубов.** Куб с любым числом граней от 2 до 120, несколько штук за раз: «3, 5, 7, 23, 30». Числа на гранях расставляются сами.
- **Сцена.** Сколько угодно объектов: выбрать, переименовать, скрыть, скопировать, убрать. У каждого свои штампы, цвет и отмена.
- **Штампы.** Текст, эмодзи, SVG и значки. Штамп правится на месте и тянется мышью по рельефу модели.
- **По рельефу.** Знак повторяет поверхность под собой, поэтому на неровной модели он везде одной глубины и не тонет в буграх.
- **Кеш.** Объекты, штампы, шрифты и настройки лежат в хранилище браузера. Обновление страницы ничего не сбрасывает.
- **Проект.** Файл `.dicestamp.json` хранит все объекты, исходные модели, штампы с координатами и добавленные шрифты.
- **Символы.** Поиск и выбор по Noto Emoji, Game Icons, Material Design Icons, Font Awesome Free и Bootstrap Icons.
- **Шрифты.** Файл TTF, OTF или WOFF, прямая ссылка, ссылка Google Fonts или название семейства. Шрифт уезжает в файл проекта.
- **Бросок.** Лоток с физикой: количество, размер и вес кубов задаются ползунками, выпавшая грань читается по нанесённым знакам.
- **Экспорт.** «Автообработка» включена по умолчанию: перед записью наносит штампы, сваривает вершины, проверяет цельность и разворачивает нормали наружу. Сохраняется выбранный объект, каждый видимый в свой файл или все видимые одним файлом. Можно выбрать папку для файлов.
- **Языки.** Русский, английский, немецкий.
- **Темы.** Полуночная, дневная яркая, высокий контраст, сепия.

## Запуск

Сайт публикуется на GitHub Pages: <https://volkula.github.io/dnd-dice-stamp/>

Локально, как у конвертера масштабов:

```bash
cd dnd-dice-stamp
docker compose up -d
```

Открыть: <http://localhost:8080>

```bash
docker compose down
docker compose logs -f
docker compose build --no-cache
docker compose up -d
```

Правки `index.html`, `styles.css` и модулей `*.js` подхватываются томом. После изменения обновите страницу.

Двойной щелчок по `index.html` не подходит: страница собирается из модулей и качает движок, шрифты и библиотеки с CDN.

## Как пользоваться

1. Добавьте STL, возьмите куб 20×20×20 или соберите кубы в генераторе. Файлы STL, SVG, шрифта и проекта можно бросить прямо на страницу.
2. Выберите объект в списке «Сцена» или кликом по нему. Штампы ставятся на выбранный объект.
3. Выберите знак: вкладка «Текст», «SVG» или «Символы».
4. Выберите «Вдавить» или «Поднять», высоту и глубину.
5. Кликните по грани: встанет новый штамп, он сразу выбран.
6. Выбранный штамп правится на месте: текст, шрифт, значок, размер, глубина, поворот.
7. Штамп можно тянуть мышью. Он скользит по поверхности и ложится по наклону грани под курсором. Shift+клик переносит выбранный штамп в точку клика, Esc снимает выбор.
8. «Нанести на модель» врезает или прибавляет все штампы объекта разом. Последнее нанесение можно отменить: штампы вернутся и их снова можно править.
9. «Сохранить STL» пишет файл в выбранную папку или в загрузки.
10. «Бросить кубик» открывает лоток с выбранным объектом.

### По рельефу

Плоский знак на неровной модели местами уходит под бугры, а местами висит над впадинами. Галочка «По рельефу» в разделе «Как нанести» это снимает: знак режется на мелкие участки, и каждый ложится на поверхность под собой. Вдавленный знак везде получает заданную глубину, поднятый везде заданную высоту.

- Галочка включена по умолчанию и хранится у каждого штампа. Её можно снять у выбранного штампа, тогда он снова плоский.
- На плоской грани обычного куба разницы нет: знак остаётся ровной призмой.
- Знак, который шире грани, перегибается через рёбра.
- На неровной модели штамп встаёт по среднему наклону поверхности под собой, а не по одному треугольнику под курсором.
- Штампы из старых проектов и из кеша тоже идут по рельефу. Если нужен прежний плоский знак, снимите галочку.
- Там, где под знаком модели нет вовсе, он продолжается на высоте ближайшего места поверхности. Знак, который вылез за край модели, там и останется.

### Генератор кубов

Кнопка «Генератор кубов» открывает окно с предпросмотром. В поле граней можно ввести несколько чисел через запятую или пробел, тогда на сцену встанет по кубу на каждое. Размер задаёт наибольший габарит в миллиметрах.

| Форма | Как устроена | Как читается |
| --- | --- | --- |
| Многогранник | Грани разложены по шару как можно ровнее. Для 4, 6, 8, 12, 20, 24 и 30 граней берётся классическое тело с одинаковыми гранями | Верхняя грань, если у каждой грани есть противоположная |
| Веретено | Бипирамида или трапецоэдр, как d10. Граней всегда чётное число | Верхняя грань |
| Цилиндр | Гранёный валик, катится на боку. Торцы острые, круглые или плоские, чисел на них нет | Верхняя грань при чётном числе граней |
| Призма | Торцы считаются гранями: N − 2 боковых и два торца. Для двух граней получается монета | Верхняя грань при чётном числе боковых |
| Свиток | Гранёный рулон на стержне с набалдашниками, катится на боку | Как цилиндр |
| Книга | Обложки с рамкой, корешок с рёбрами и обрез: N − 2 боковых и две обложки. Для шести граней обложка прямоугольная | Как призма |
| Барабан | Обечайка между обручами, стяжки по рёбрам, кожи считаются гранями. Для двух граней получается бубен | Как призма |
| Котелок | Гранёный котелок на трёх ножках с толстым краем, числа на пузе | Как цилиндр |
| Тарелка или миска | Донышко, расширение, борт и углубление. Для двух граней получается тарелка, для большего числа миска | Как призма |
| Кубок | Ножка шириной с чашу, поэтому лежит ровно. Числа на чаше | Как цилиндр |
| Ваза | Донышко, пузо, горло и венчик. Числа на пузе | Как цилиндр |

Тематические формы декоративные: равных шансов у граней они не обещают. Котелок, кубок и ваза в лотке иногда встают на донышко или на горлышко, тогда лоток показывает «?» и бросок повторяют. У котелка, кубка и вазы меньше пяти граней не бывает: для d3 и d4 граней делается вдвое больше.

Когда форма не может иметь столько граней (трёхгранный многогранник, семигранное веретено), граней делается вдвое больше и каждое число стоит на двух. То же делает галочка «Каждое число на двух противоположных гранях».

У куба с нечётным числом граней сверху оказывается ребро или вершина. Такой куб читается по грани, на которой лежит, как d4. Чтобы читать сверху, включите удвоение.

Числа ставятся обычными штампами: их можно править, двигать, удалять и наносить на модель. На противоположных гранях числа в сумме дают N + 1, как у обычных костей. У 6 и 9 стоит точка, когда на кубе есть обе.

### Шрифты

В поле добавления шрифта годится любое из четырёх:

- прямая ссылка на `.ttf`, `.otf` или `.woff`;
- ссылка вида `https://fonts.google.com/specimen/Cinzel`;
- ссылка `https://fonts.googleapis.com/css2?family=...`;
- название семейства, например `Cinzel`.

Семейства берутся с Fontsource: латиница и, если есть, кириллица. WOFF2 не читается. Сервер по прямой ссылке должен разрешать запросы с других сайтов (CORS). Символы, которых нет в выбранном шрифте, берутся из Roboto, затем из Noto Emoji.

### Бросок

Столкновения считаются по выпуклой оболочке модели. Выпавшей считается грань, чей знак смотрит вверх. Если сверху оказалось ребро или вершина (d4, кубы с нечётным числом граней), читается грань, на которой куб лежит. «?» значит, что куб встал так, что знак не прочитать: на торец, на ребро у стенки, на другой куб. Вес не меняет свободное падение, поэтому он показан иначе: тяжёлый куб летит медленнее и меньше отскакивает.

### Папка экспорта

Выбор папки работает в Chrome и Edge. В Firefox и Safari файлы уходят в загрузки.

## Стек

- HTML, CSS, JavaScript без сборки
- [three.js](https://threejs.org/), рисование STL
- [manifold-3d](https://github.com/elalish/manifold), булевы операции
- [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh), поиск поверхности под знаком
- [opentype.js](https://opentype.js.org/), разбор шрифтов
- [Rapier](https://rapier.rs/), физика лотка
- nginx в Docker
